# Product Management — React frontend

React (Vite) + Axios app: Login, product list, add, edit, delete, logout. Talks only to the LavaLust API.

1. Copy `.env.example` to `.env` and set `VITE_API_URL` to the API URL.
2. `npm install`
3. `npm run dev` (local) or `npm run build` (output in `dist/`)

Render Static Site: build command `npm install && npm run build`, publish directory `dist`, env var `VITE_API_URL`.
See SETUP_GUIDE.md for the full walkthrough.
